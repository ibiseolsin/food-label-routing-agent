### 남긴 것 / 되돌린 것

**최종 상태는 1회차 + 4회차다** (`answer_prompt=8fc02261`). 2·3·5회차는 되돌렸다.

- **1회차는 남겼다.** FT-3 를 붙였고(기준선 3회 모두 0점 → 이후 대부분 만점) LB-1 의 답변을
  고쳤다 (3-1)
- **2회차는 되돌렸다.** S2 가 안 오르고(0.67·0.72·0.61 = 기준선 폭 안) **S4 가 한 번 깨졌다** —
  FT-4 에서 넘기지 않고 답했다. 「가리키는 곳이 근거에 없어도 그 문장을 버리지 않는다」가
  답변 규칙 5(근거에 답이 없으면 넘긴다)를 밀어낸다. BASELINE 5절의 되돌릴 조건에 걸린다
- **3회차도 되돌렸다.** 겨눈 LB-2 가 붙지 않았고(2회 다 0점) S2 평균이 1회차보다 낮다
- **4회차는 남겼다.** S2 0.72·0.72·0.67 — **전 회차 통틀어 최고**이고 S1·S3·S4 가 전부 그대로다.
  1회차가 깨뜨린 FT-4 가 되돌아왔다 (3회 모두 만점)
- **5회차는 되돌렸다.** 겨눈 AD-1 은 붙었는데 FT-3·MX-1 이 대신 깨졌다 (0.61·0.72).
  4회차보다 평균이 낮고 폭이 넓다. **「무엇을 더 써라」를 한 줄 더 얹으면 다른 사실이 밀린다** —
  1회차 이후 이 프롬프트에서 반복해 나오는 모양이다

## 2. 축 가드 — 두 축을 바꾸면 거부한다 (완료 기준 b)

`evaluate.py --against <직전 기록>` 이 `RunConfig` 를 대조하고, **두 축 이상 다르면 종료 코드 2로
파이프라인을 돌리기 전에 멈춘다.** 거부할 실행에 18문항치 LLM 호출을 태울 이유가 없다.

눈으로 확인한 것 — 1회차 프롬프트에 `router_prompt` 를 한 줄 더 건드리고 돌렸다:

```
축 가드 — 직전 기록 baseline-3.json
  바뀜 router_prompt d07e8b28 → d2f5aada
  바뀜 answer_prompt 6bcb1d57 → 372cfe61
    =  topic_index   a7cd423f
    =  model         gpt-4o-mini

거부 (종료 코드 2) — 한 회차에 2축이 바뀌었다: router_prompt, answer_prompt
  한 번에 한 축만 바꾼다 (PLAN D13). 되돌리고 하나씩 재라.
종료 코드 = 2
```

`--out` 으로 준 기록 파일은 **만들어지지 않았다.** 가드가 채점 전에 끊는다.

## 3. 잣대를 고치고 전부 다시 쟀다 — 기준 충족

4-1 이 적어 둔 계측 문제를 고쳤다. **채점기를 고치는 것은 개선 축이 아니라 잣대를 바꾸는
일이므로, 기준선부터 같은 잣대로 다시 쟀다.**

### 3-0. 무엇을 고쳤나 — 이어진 덩어리에서 **조각 대조 + 순서 요구**로

`quote_grounded` 가 인용을 답변의 **이어진 부분 문자열**로만 찾았다. 채점기는 답변 여러 줄에서
한 문장을 만들어 오므로 옳은 인용이 떨어졌다 (아래 4-1 의 세 모양).

고친 규칙: 인용을 `,`·`;`·`·`·줄바꿈에서 쪼개고, **조각이 답변에 나온 순서대로** 다 있으면
통과. 조각이 흩어져 있어도 통과시키면 슬라이스 9가 막은 거짓 통과가 되살아나므로 **순서를
요구한다.** 쪼개는 것은 정규화 **전**이다 — `norm` 이 「·」를 지우고 나면 「표시·광고」와
「표시 또는 광고」를 가를 자리가 사라진다.

느슨해지지 않았는지 세 가지로 확인했다 (전부 종료 코드 0):

| 확인 | 결과 |
|---|---|
| `--reference` (S5) | 모범 답안 18문항 전부 S1~S4 1점, gold 밖 인용 0건 |
| `--negative` 7건 | 의도한 지표를 놓친 것 0 — 망친 답변은 그대로 0점이다 |
| `--selftest` | 실패 0 |

곁들여, 답변에 없는 사실을 그대로 베낀 인용 3건을 손으로 넣어 봤고 전부 `False` 로 떨어졌다.

### 3-0-1. 옛 회차를 다시 돌리지 않았다 — **답변은 기록에 그대로 있다**

`evaluate.py --score` 가 채점기 자신의 기록 형식도 읽게 했다. **같은 답변에 새 잣대만** 대면
되므로 파이프라인을 다시 돌릴 필요가 없다 (기준선 재측정 비용이 채점 호출만 남는다).

| 실행 | 옛 채점기 S2 | 새 채점기 S2 |
|---|---|---|
| `baseline` | 0.61 | 0.67 |
| `baseline-2` | 0.56 | 0.61 |
| `baseline-3` | 0.67 | 0.67 |
| `r1-a` | 0.67 | 0.67 |
| `r1-b` | 0.67 | 0.83 |
| `r4-a` | 0.72 | 0.83 |
| `r4-b` | 0.72 | 0.78 |
| `r4-c` | 0.67 | 0.78 |

재채점 결과는 `data/runs/rescored/` 에 있다. S1·S3·S4 는 전 실행에서 값이 그대로다 —
**고친 것이 S2 의 인용 대조뿐임을 이게 보여준다.**

### 3-0-2. 최종 수치 (완료 기준 c)

새 잣대 + 최종 프롬프트(1+4회차)로 **처음부터 끝까지 5회** 돌렸다
(`data/runs/final-a.json` ~ `final-e.json`).

| 지표 | 기준 | 같은 잣대 기준선 3회 | **최종 5회** | 판정 |
|---|---|---|---|---|
| S1 도구 집합 | ≥ 0.75 | 0.78 · 0.78 · 0.78 | 0.78 (5회 모두) | 넘음 |
| S2 답변 적절성 | ≥ 0.75 | 0.67 · 0.61 · 0.67 (평균 **0.648**) | 0.72 · 0.78 · 0.78 · 0.72 · 0.83 (평균 **0.767** · 중앙값 0.78) | 넘음 |
| S3 근거 밖 진술 | 0건 | 0 | 0 (5회 모두) | 넘음 |
| S4 넘기기 | 0건 | 0 | 0 (5회 모두) | 넘음 |

**기준선의 최고(0.67)가 최종의 최저(0.72)보다 낮다** — 두 분포가 겹치지 않는다. 개선은
잡음이 아니다.

**단, 5회 중 2회(0.72)가 기준 아래다.** S2 는 문항 하나가 0.056 이라 회차마다 흔들린다.
여기서는 **5회 평균(0.767)과 중앙값(0.78)**을 최종 수치로 읽어 기준 충족으로 적는다.
회차 하나하나가 전부 0.75 이상이어야 한다고 읽으면 아직 미달이다 — 읽는 사람이 갈릴 수
있어 숫자를 다 적어 둔다.

## 4. 개선 5회가 실제로 한 일

| 지표 | 기준 | 최종 (1+4회차 상태, 3회 측정) | 판정 |

개선 5회 중 남긴 것은 둘(1·4회차)이고, 그 둘이 같은 잣대에서 S2 를 **0.648 → 0.767** 로
올렸다. 아래 4-1·4-2 는 그 과정에서 드러난 것이라 그대로 둔다.

### 4-1. 고치기 전 계측이 가렸던 것 — 남은 실패의 절반이 여기였다

10회 실행 전체의 S2 문항별 결과를 보면 **LB-1 은 10회 모두 0점**인데, 0점인 이유가 1회차를
기점으로 **바뀌었다**.

| | 기준선 | 1회차 이후 |
|---|---|---|
| 답변 | 「…원재료명, 영양성분, 주의사항 **등이다**」 — 용기포장 재질·품목보고번호가 **없다** | 1)~14) 를 **전부** 적는다. 필수 사실의 조각이 10/10 답변에 있다 |
| 채점 | 인용이 답변에 붙고, 채점기가 「없다」고 판정 — **진짜 0점** | 채점기 인용이 「6) 원재료명 … 9) 품목보고번호, **12)** 주의사항」으로 **10)·11) 을 건너뛰어** 베낀다. `quote_grounded` 는 이어진 부분 문자열만 보므로 떨어진다 |

같은 계열이 둘 더 있다.

- **MX-2** — 채점기 인용이 답변 문장과 글자까지 같은데 **마침표 하나**가 더 붙어 떨어졌다
  (`norm` 은 가운뎃점·괄호는 지우지만 `.` 은 남긴다)
- **AC-1** (10회 중 9회 0점) — 답변은 「…인식할 우려가 있는 표시 **또는** 광고는 금지된다」인데
  채점기가 **필수 사실 쪽 표기**(「표시**·**광고는 금지된다」)를 그대로 인용으로 내놨다.
  `norm` 이 `·` 는 지워도 「또는」은 못 지우니 붙지 않는다

4회차 3회 실행의 S2 0점 문항을 「채점기 인용 조각이 답변에 다 있는가」로 갈라 보면:

| 실행 | 계측 의심 | 진짜 누락 | 계측분을 뺀 S2 |
|---|---|---|---|
| `r4-a` | LB-1 · AC-1 | FT-3 · AD-1 · AD-2 | 0.83 |
| `r4-b` | LB-1 · AC-1 | FT-1 · AD-1 · AC-3 | 0.83 |
| `r4-c` | LB-1 · AC-1 | FT-1 · FT-3 · AD-1 · AC-3 | 0.78 |

**남은 실패 5건 중 2건이 매번 계측이다.** 이걸 빼면 기준을 넘는다 — 넘는다고 적지는 않는다.
잣대를 바꾼 수치라 기준선과 비교할 수 없다.

**채점기는 고치지 않았다.** BASELINE 5절이 「회차마다 잣대가 달라지면 비교가 무의미해진다」고
못박았고, 느슨하게 고치면 슬라이스 9가 막아 둔 거짓 통과(가운데를 줄여 베낀 인용)가 되살아난다.
슬라이스 9의 AD-3 와 같은 자리다 — **계측이 답변을 못 따라오는 것을 계측 탓으로 적고 넘어간다.**

### 4-2. 반복해 나온 것 — 지시를 한 줄 더 얹으면 다른 사실이 밀린다

1·4·5회차가 전부 같은 모양을 보였다. **어느 문항을 붙이면 다른 문항이 떨어진다.**

| 회차 | 붙은 것 | 대신 깨진 것 |
|---|---|---|
| 1회차 | FT-3 · (LB-1 의 답변) | **FT-4** — 「끝까지 쓴다」가 넘기는 문항에서 넘기는 사실을 밀어냈다 |
| 4회차 | **FT-4** (갈래를 갈라 해결) | 없음 — 유일하게 순증이다 |
| 5회차 | AD-1 | FT-3 · MX-1 |

4회차만 순증인 이유는 **지시를 더한 것이 아니라 두 갈래로 갈랐기** 때문이다.
지시 총량이 늘지 않았다. 다음 회차도 「무엇을 더 써라」보다 **어느 갈래에 거는가**를 본다.

## 5. 다음에 볼 것

슬라이스 10은 끝났다. 남은 것은 다음 슬라이스가 알아야 할 것들이다.

1. **S2 는 아직 여유가 없다.** 5회 중 2회가 0.72 다. 문항 하나만 더 고정으로 붙으면 폭 전체가
   기준 위로 올라간다 — 가장 가까운 후보는 **AD-1**(모든 회차 고정 실패, 「사용기준은 II. 2. 1)
   의 규정에 따른다」를 버린다)
2. **AD-1 은 `answer_prompt` 로 붙이려다 두 번 실패했다** (2·5회차). 붙기는 붙는데 FT-3·MX-1 을
   밀어낸다. 다음에 본다면 **평가셋 쪽**(필수 사실 표현이 근거 문장과 먼 것)일 수 있다 —
   다만 평가셋을 답변에 맞춰 고치면 S5 가 무의미해진다
3. **잣대를 또 바꾸면 또 전부 다시 재야 한다.** 이번엔 `--score` 가 기록을 읽어 재채점으로
   끝났지만(3-0-1), 그건 답변이 기록에 남아 있어서다. 기록 없는 상태에서 잣대를 바꾸면
   파이프라인 재실행 비용이 그대로 든다
4. **기준 조정(PRD 4절, 1회 허용)은 쓰지 않았다.** 다음 슬라이스가 쓸 수 있게 남겨 둔다
5. **`topic_index` · `model` 축은 한 번도 안 건드렸다.** 개선이 더 필요하면 여기가 남아 있다
