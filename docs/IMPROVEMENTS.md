### 남긴 것 / 되돌린 것

**최종 상태는 1회차 + 4회차다** (`answer_prompt=8fc02261`). 2·3·5회차는 되돌렸다.

- **1회차는 남겼다.** FT-3 를 붙였고(기준선 3회 모두 0점 → 이후 대부분 만점) LB-1 의 답변을
  고쳤다 (3-1)
- **2회차는 되돌렸다.** S2 가 안 오르고(0.67·0.72·0.61 = 기준선 폭 안) **S4 가 한 번 깨졌다** —
  FT-4 에서 넘기지 않고 답했다. 「가리키는 곳이 근거에 없어도 그 문장을 버리지 않는다」가
  답변 규칙 5(근거에 답이 없으면 넘긴다)를 밀어낸다. BASELINE 5절의 되돌릴 조건에 걸린다
- **3회차도 되돌렸다.** 겨눈 LB-2 가 붙지 않았고(2회 다 0점) S2 평균이 1회차보다 낮다
- **4회차는 남겼다.** S2 0.72·0.72·0.67 — **전 회차 통틀어 최고**이고 S1·S3·S4 가 전부 그대로다.
  1회차가 깨뜨린 FT-4 가 되돌아왔다 (3회 모두 만점)
- **5회차는 되돌렸다.** 겨눈 AD-1 은 붙었는데 FT-3·MX-1 이 대신 깨졌다 (0.61·0.72).
  4회차보다 평균이 낮고 폭이 넓다. **「무엇을 더 써라」를 한 줄 더 얹으면 다른 사실이 밀린다** —
  1회차 이후 이 프롬프트에서 반복해 나오는 모양이다

## 2. 축 가드 — 두 축을 바꾸면 거부한다 (완료 기준 b)

`evaluate.py --against <직전 기록>` 이 `RunConfig` 를 대조하고, **두 축 이상 다르면 종료 코드 2로
파이프라인을 돌리기 전에 멈춘다.** 거부할 실행에 18문항치 LLM 호출을 태울 이유가 없다.

눈으로 확인한 것 — 1회차 프롬프트에 `router_prompt` 를 한 줄 더 건드리고 돌렸다:

```
축 가드 — 직전 기록 baseline-3.json
  바뀜 router_prompt d07e8b28 → d2f5aada
  바뀜 answer_prompt 6bcb1d57 → 372cfe61
    =  topic_index   a7cd423f
    =  model         gpt-4o-mini

거부 (종료 코드 2) — 한 회차에 2축이 바뀌었다: router_prompt, answer_prompt
  한 번에 한 축만 바꾼다 (PLAN D13). 되돌리고 하나씩 재라.
종료 코드 = 2
```

`--out` 으로 준 기록 파일은 **만들어지지 않았다.** 가드가 채점 전에 끊는다.

## 3. 완료 기준 (c) 는 못 넘겼다 — S2 0.70

| 지표 | 기준 | 최종 (1+4회차 상태, 3회 측정) | 판정 |
|---|---|---|---|
| S1 | ≥ 0.75 | 0.78 · 0.78 · 0.78 | 넘음 |
| S2 | ≥ 0.75 | **0.72 · 0.72 · 0.67** (평균 0.70) | **못 넘음** |
| S3 | 0건 | 0 · 0 · 0 | 넘음 |
| S4 | 0건 | 0 · 0 · 0 | 넘음 |

기준선 평균 0.61 (0.61·0.56·0.67) → 최종 평균 0.70. **기준선 폭의 위를 벗어났지만
0.75 에는 한 문항 반이 모자란다** (0.75 = 13.5/18, 지금 13·13·12).
개선 5회를 썼고 남긴 것은 둘이다.

### 3-1. 그래도 답변은 고쳐졌다 — 남은 실패의 **절반이 계측**이다

10회 실행 전체의 S2 문항별 결과를 보면 **LB-1 은 10회 모두 0점**인데, 0점인 이유가 1회차를
기점으로 **바뀌었다**.

| | 기준선 | 1회차 이후 |
|---|---|---|
| 답변 | 「…원재료명, 영양성분, 주의사항 **등이다**」 — 용기포장 재질·품목보고번호가 **없다** | 1)~14) 를 **전부** 적는다. 필수 사실의 조각이 10/10 답변에 있다 |
| 채점 | 인용이 답변에 붙고, 채점기가 「없다」고 판정 — **진짜 0점** | 채점기 인용이 「6) 원재료명 … 9) 품목보고번호, **12)** 주의사항」으로 **10)·11) 을 건너뛰어** 베낀다. `quote_grounded` 는 이어진 부분 문자열만 보므로 떨어진다 |

같은 계열이 둘 더 있다.

- **MX-2** — 채점기 인용이 답변 문장과 글자까지 같은데 **마침표 하나**가 더 붙어 떨어졌다
  (`norm` 은 가운뎃점·괄호는 지우지만 `.` 은 남긴다)
- **AC-1** (10회 중 9회 0점) — 답변은 「…인식할 우려가 있는 표시 **또는** 광고는 금지된다」인데
  채점기가 **필수 사실 쪽 표기**(「표시**·**광고는 금지된다」)를 그대로 인용으로 내놨다.
  `norm` 이 `·` 는 지워도 「또는」은 못 지우니 붙지 않는다

4회차 3회 실행의 S2 0점 문항을 「채점기 인용 조각이 답변에 다 있는가」로 갈라 보면:

| 실행 | 계측 의심 | 진짜 누락 | 계측분을 뺀 S2 |
|---|---|---|---|
| `r4-a` | LB-1 · AC-1 | FT-3 · AD-1 · AD-2 | 0.83 |
| `r4-b` | LB-1 · AC-1 | FT-1 · AD-1 · AC-3 | 0.83 |
| `r4-c` | LB-1 · AC-1 | FT-1 · FT-3 · AD-1 · AC-3 | 0.78 |

**남은 실패 5건 중 2건이 매번 계측이다.** 이걸 빼면 기준을 넘는다 — 넘는다고 적지는 않는다.
잣대를 바꾼 수치라 기준선과 비교할 수 없다.

**채점기는 고치지 않았다.** BASELINE 5절이 「회차마다 잣대가 달라지면 비교가 무의미해진다」고
못박았고, 느슨하게 고치면 슬라이스 9가 막아 둔 거짓 통과(가운데를 줄여 베낀 인용)가 되살아난다.
슬라이스 9의 AD-3 와 같은 자리다 — **계측이 답변을 못 따라오는 것을 계측 탓으로 적고 넘어간다.**

### 3-2. 반복해 나온 것 — 지시를 한 줄 더 얹으면 다른 사실이 밀린다

1·4·5회차가 전부 같은 모양을 보였다. **어느 문항을 붙이면 다른 문항이 떨어진다.**

| 회차 | 붙은 것 | 대신 깨진 것 |
|---|---|---|
| 1회차 | FT-3 · (LB-1 의 답변) | **FT-4** — 「끝까지 쓴다」가 넘기는 문항에서 넘기는 사실을 밀어냈다 |
| 4회차 | **FT-4** (갈래를 갈라 해결) | 없음 — 유일하게 순증이다 |
| 5회차 | AD-1 | FT-3 · MX-1 |

4회차만 순증인 이유는 **지시를 더한 것이 아니라 두 갈래로 갈랐기** 때문이다.
지시 총량이 늘지 않았다. 다음 회차도 「무엇을 더 써라」보다 **어느 갈래에 거는가**를 본다.

## 4. 다음 회차가 읽을 것

**`answer_prompt` 축은 여기까지다.** 5회를 썼고 4회차만 순증이었으며, 그 순증도 지시를 더한
것이 아니라 갈래를 가른 것이었다. 남은 진짜 실패는 AD-1(15회 중 13회) 하나가 고정이고
나머지는 회차마다 자리를 바꾼다 — 이 축에서 더 짜낼 것이 보이지 않는다.

1. **계측이 먼저다.** 3-1 의 세 모양(열거 가운데 건너뛴 인용 · 마침표 하나 · 「또는」↔「·」)은
   전부 `quote_grounded` 의 **이어진 부분 문자열** 규칙에서 나온다. 고치려면 **기준선 3회를
   같은 잣대로 다시 재야** 이 문서의 표가 유지된다. 비용은 기준선 3회 + 회차별 재측정이다
2. **느슨하게 고치면 안 된다.** 슬라이스 9가 막은 거짓 통과(필수 사실을 그대로 베낀 인용)가
   되살아난다. 「인용을 문장 단위로 쪼개 각 조각이 답변에 있는지」처럼 **조각 대조**로 가고,
   `--negative` 7건과 `--reference` 로 거짓 통과가 안 생기는지 먼저 확인한다
3. **AD-1 은 남은 유일한 고정 실패다.** 5회차 방식(가리키는 말 옮기기)은 붙이긴 하는데
   FT-3·MX-1 을 밀어낸다. `answer_prompt` 가 아니라 **평가셋 쪽**(필수 사실 표현이 근거 문장과
   먼 것)을 볼 자리일 수 있다 — 다만 평가셋을 답변에 맞춰 고치면 S5 가 무의미해진다
4. **기준 조정은 PRD 4절이 한 번 허용한다** — 아직 쓰지 않았다. 쓰면 `REPORT.md` 에 이유를 적는다
